# ♻️ SortSmart AI
### AI-Powered Waste Segregation & Smart Campus Waste Management

**Scan. Sort. Save the Planet.**

SortSmart AI is an intelligent waste management platform designed to make waste segregation simpler, smarter, and more engaging. Using AI-powered image analysis, the platform helps users identify different types of waste, understand how to dispose of them responsibly, and encourage sustainable habits through gamification.

Our goal is to promote cleaner campuses, smarter communities, and a more sustainable future through technology.

---

## 🌍 The Problem

Improper waste segregation is a major challenge in colleges, residential societies, offices, and public spaces.

- People often struggle to identify the correct waste category.
- Recyclable materials frequently end up mixed with general waste.
- Lack of awareness discourages responsible disposal.
- Institutions have limited visibility into waste generation and participation.

## 💡 Our Solution

SortSmart AI combines artificial intelligence, sustainability education, gamification, and analytics into one platform.

Users can scan waste items, receive AI-assisted identification, follow disposal recommendations, and earn Green Points for responsible participation.

Institutions can use an analytics dashboard to understand waste categories and monitor engagement.

---

## 🔄 How It Works

1. **Scan:** The user uploads or captures an image of a waste item.
2. **Analyze:** The AI analyzes the image and identifies the likely waste category.
3. **Guide:** The platform provides appropriate disposal recommendations.
4. **Reward:** Users earn Green Points for eligible sustainable activities.
5. **Monitor:** Institutional dashboards display waste and engagement insights.

## 🛠️ Getting Started

### Prerequisites
- Node.js (LTS recommended)
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/mayankmalik08/sortsmart-ai.git
```

Navigate to the project directory:

```bash
cd sortsmart-ai
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

For a production build:

```bash
npm run build
```

*If the project uses additional environment variables or API credentials, configure them according to the project's setup before running the application.*

---

## 🔐 Environment Variables

If Gemini API or backend integrations are enabled, configure the required environment variables using a local `.env` file.

Example:

```env
GEMINI_API_KEY=your_api_key
```

Never commit API keys, passwords, or other secrets to GitHub. Use secure server-side handling for sensitive credentials.
